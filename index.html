Phone setup tips

Install it as an app

Once installed it opens full-screen with its own icon and works with no signal.

Android (Chrome): ⋮ → Add to home screen → Install.
Samsung Internet: ☰ → Add page to → Home screen.
Firefox (Android): ⋮ → Add app to Home screen.
iPhone / iPad (Safari): Share ⎙ → Add to Home Screen.

On Android, long-press the icon to jump straight to Boss Lookup, Type Chart or Search Builder.

Use it next to the game

Most Android phones: open Recents (the app switcher), tap the GO Tools icon above its preview and choose Split screen. The wording varies by brand.

Samsung: the same menu also has Open in pop-up view for a small floating window. If Pokémon GO refuses to split, turn on Settings → Advanced features → Labs → Multi window for all apps.

iPhone: there's no split screen, but swiping left/right along the bottom edge flips between GO and GO Tools instantly, and both stay where you left them.

The type chart's Fit button shrinks it to whatever window size it gets.

Faster access

Samsung Edge panel: Settings → Display → Edge panels → turn on Apps, then add GO Tools. Swipe in from the edge mid-raid.

iPhone Back Tap: make a Shortcut that opens this site, then pick it under Settings → Accessibility → Touch → Back Tap. Double-tap the back of the phone to open it.

Stylus or mouse

Hover a pen (S Pen, Apple Pencil) or mouse over a type chart cell to see the matchup without tapping.
