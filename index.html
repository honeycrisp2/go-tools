Phone setup tips (Samsung)

Install it

In Chrome: ⋮ menu → Add to home screen → Install. In Samsung Internet: ☰ menu → Add page to → Home screen. Once installed it opens full-screen and works with no signal. Long-press the icon to jump straight to a tool.

Edge panel

Settings → Display → Edge panels → turn on Apps, then edit it and add GO Tools. Swipe in from the edge mid-raid to open it.

Next to the game

With GO open, open Recents, tap the GO Tools icon at the top of its card and choose Open in pop-up view (floating window) or Open in split screen view. If Pokémon GO refuses to split, turn on Settings → Advanced features → Labs → Multi window for all apps. The type chart's Fit button shrinks it to whatever window size it gets.

S Pen

Hover the pen over a type chart cell to see the matchup without tapping.
